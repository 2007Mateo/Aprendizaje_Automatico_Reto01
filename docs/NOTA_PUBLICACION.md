# Alcance de la publicación en GitHub

Este repositorio contiene los avances del equipo: auditoría y notebook de Hito 1, PDF del informe, propuesta previa, dos Excel de preparación, los CSV de 221/215/204 y las 17 incidencias, notebook y plan del Hito 2, scripts y mapa de continuidad.

**Material docente no republicado:** `Reto01.pdf` y `formatoInforme.pdf` se conservan en el archivo ZIP local entregado al equipo, pero no se publican en este repositorio público. Por ello, la carpeta `00_enunciado` aparece solo en el paquete local. El manifiesto SHA-256 se diseñó para el paquete completo e incluye los dos documentos de origen.

**Fuentes de datos:** `fuente_relevante_221.csv` contiene 41 columnas relevantes exportadas de los Excel del equipo, no las 213 columnas completas del CSV oficial. Los municipios y transformaciones de las matrices se pueden revisar con los verificadores. Para reproducir el origen completo, descargar la **edición INEC GIRS 2024**, no mezclar años.

**Estado:** el Hito 2 se considera preparado; el script en `03_hito3_preparacion` es un punto de partida para **ejecutar, revisar e interpretar** el Hito 3, no un informe final ni un modelo seleccionado.
